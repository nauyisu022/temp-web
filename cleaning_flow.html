INPUT
原始 description

Level 1 · 预处理
结构规范化
HTML 标签 控制字符 零宽字符 Emoji 删除 空白规范化
Level 2 · 段落级过滤
按 \n\n 分段 → 整段判断
含 规格/型号/认证/产地 → 硬保护
命中 6 类噪音关键词 → 逐行扫描 → 有 fact 行则保留，全 noise 则删
📦 物流 ↩ 退换 💬 客服 🏪 店铺 ⚠ 免责 ⛔ 警告
Level 3 · 行级输出
逐行判断 → 原样输出
规格/型号/认证/产地 → fact（保留）
≤60字符 + 噪音词 + 无规格单位 → 删除
其余 → keep · 全局去重 · 不拆句不重组
OUTPUT
description_cleaned
保留产品事实 · 原始行格式 · 无 emoji · 无运营噪音
