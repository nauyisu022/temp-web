2026-04-15 Phase 1 到 Phase 5 结果

本轮最终采用的评估口径

最终评估保留两类弱监督锚点，再配合结构单调性：

  1. surface（词面锚点）
  2. search（搜索行为锚点）
  3. edge_monotonicity（所有父子边上，子词分数高于父词的比例）
  4. primary_edge_monotonicity（单父投影上的同类比例）

原先尝试过再加一层 graph（图位置锚点），后来拿掉，原因有两点：

  1. 这会把图位置重新拿来评价图分数，本身有偏置。
  2. 这一层在全量台湾上额外耗时明显，但新增信息有限。
