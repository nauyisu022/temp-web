台湾搜索词结构实验方案

source: TW_SEARCH_TREE_EXPERIMENT_PLAN.md updated: 2026-04-15 18:21 UTC

一、实验目标

这轮实验只聚焦台湾搜索词库本身，不先考虑 reward（奖励）接法。

目标有两层：

  1. 在 TW（台湾）全量搜索词上，比较多种建图方案，产出一版可信的森林或 DAG（有向无环图）结构。
  2. 在每种结构上进一步导出连续分数，用来判断一个词更偏 泛词，还是更偏 长尾词。

最终要解决的不是“图好不好看”，而是：

  1. 哪种结构更稳定
  2. 哪种结构更能支撑 泛词 / 长尾词 区分
  3. 哪种连续分数最可用

二、为什么要做这轮实验

当前问题并不是单纯“词库命中率低”，而是：

  1. 词库反馈本身稀疏
  2. 二值命中信号过硬
  3. 只看命中，无法稳定区分： - 完整搜索词 - 安全碎词 - 泛词 - 长尾词

因此需要先把全量搜索词组织起来，再从结构中提取“一个词有多泛、有多具体”的依据。

台湾是合适的首个实验区，原因有三点：

  1. CJK（中文连续字形）词面包含关系天然更强
  2. 已经具备全量建图、局部树图、多父图和全量浏览器基础
  3. 便于观察词面结构、分支结构和搜索行为之间的关系

三、实验核心问题

这轮实验围绕两个问题展开：

1. 台湾搜索词之间应如何组织成结构

也就是：

  1. 哪些词应当互相连边
  2. 父子边应该如何筛选
  3. 多父边是否应该保留
  4. 图结构应当更像树，还是更像真实 DAG

2. 如何从结构中推导一个连续分数

这个分数先定义为：

specificity score（具体度分数）

语义约定：

  • 0 更偏泛词
  • 1 更偏长尾词

这个分数当前不直接判定“是不是理想搜索词”，只回答“这个词在结构上有多具体”。

四、实验边界

本轮要做

  1. 台湾全量词库结构实验
  2. 建图方案多路对比
  3. 连续分数多路对比
  4. 结构稳定性和区分能力评估
  5. 全量浏览器抽样检查

本轮先不做

  1. 不直接改 reward
  2. 不先做跨地区联合方案
  3. 不依赖大量人工标注
  4. 不先做监督式训练模型

人工参与只保留在最后少量抽检阶段，用来辅助确认方向。

五、输入数据

当前台湾可直接使用的数据包括：

  1. 搜索词节点 - search_term - impressions - clicks - orders_7d - gmv_7d - cost

  2. 现有结构能力 - 单父树投影 - 多父图索引 - 全量 DAG - 局部树图页面 - 台湾全量浏览器

六、实验总框架

实验拆成两条并行主线：

主线 A：建图方案实验

目标是找到最稳的台湾全量结构。

主线 B：连续分数实验

目标是在不同图结构上，比较哪种 specificity score 最能区分泛词与长尾词。

最后不是分别选最优，而是选一组组合：

最佳结构方案 + 最佳连续分数方案

七、主线 A：建图方案矩阵

方案 A1：Lexical Only

只使用词面关系。

规则：

  1. 连续字串包含召回候选父词
  2. 父词更短
  3. 父词存在于词库

这是最朴素的基线。

优点：

  1. 简单
  2. 易解释
  3. 对中文词面天然有效

风险：

  1. 容易把资讯词挂进来
  2. 容易产生碎片边
  3. 多义词容易混挂

方案 A2：Lexical + Frequency

在 A1 上增加搜索数据约束。

增加条件：

  1. 父词曝光高于子词
  2. 父子曝光比例处于合理区间
  3. 活跃度更稳定的词优先作为父词

目标：

减少明显不合理的边。

优点：

  1. 能压掉一部分极端错挂
  2. 更接近真实搜索层级

风险：

  1. 仍然容易保留资讯型边
  2. 高频歧义词可能更强势

方案 A3：Lexical + Frequency + Graph Regularization

在 A2 上增加结构约束。

约束包括：

  1. 多父边数量控制
  2. 父边方向一致性
  3. 分支宽度异常检测
  4. 深度异常检测
  5. 极弱边裁剪

目标：

让结构更稳定，不只是局部对。

优点：

  1. 更适合全量图
  2. 可减少图污染
  3. 更利于后续连续分数稳定

风险：

  1. 规则复杂度更高
  2. 调参成本更大

方案 A4：Lexical + Frequency + Quality Signals

在 A3 基础上进一步把搜索行为信号纳入边筛选。

可加入：

  1. ctr
  2. orders_7d
  3. gmv_7d
  4. gpm

注意：

这一步不是直接判断词好坏，而是用行为信号辅助判断这条边像不像真实上下位关系。

例如：

  1. 高曝光但极低商业价值的词，可能更偏资讯词
  2. 低曝光但高成交的词，可能是强长尾

优点：

  1. 更接近实际搜索价值
  2. 可能进一步改善边质量

风险：

  1. 容易把“结构问题”和“商业问题”混在一起
  2. 某些类目会被销量偏置带偏

八、主线 B：连续分数方案矩阵

方案 B1：specificity_lexical

只看词面。

特征候选：

  1. 字符长度
  2. 是否带品牌
  3. 是否带型号
  4. 是否带规格
  5. 是否带修饰信息
  6. 是否像完整短语

作用：

做最低成本基线。

方案 B2：specificity_graph

只看图结构位置。

特征候选：

  1. 深度
  2. 父节点数
  3. 子节点数
  4. 后代规模
  5. 是否根节点
  6. 是否叶子
  7. 所处子树规模

作用：

验证图本身能不能稳定给出具体度。

方案 B3：specificity_search

只看搜索数据。

特征候选：

  1. log(impressions)
  2. ctr
  3. orders_7d / impressions
  4. gmv_7d / impressions
  5. 活跃度

作用：

观察只用行为信号时，是否已经能粗分层级。

方案 B4：specificity_hybrid

综合词面、图结构和搜索行为。

这是当前最可能成为最终主方案的一路。

思路：

  1. 先把每类特征分别标准化
  2. 再按实验比较权重
  3. 输出 0-1 连续分数

优点：

  1. 同时利用词形、结构和搜索行为
  2. 区分能力上限最高

风险：

  1. 可解释性会弱于单一路方案
  2. 调试复杂度更高

九、弱监督基准设计

尽量不使用人工标注，因此先构造一组“弱标签锚点”作为比较基准。

9.1 强泛词锚点

典型特征：

  1. 高曝光
  2. 高分支
  3. 位于根部或近根部
  4. 词短

这类词应在 specificity score 上靠近低分区域。

9.2 强长尾锚点

典型特征：

  1. 位于深层
  2. 叶子或近叶子
  3. 含品牌、规格、型号、属性或场景
  4. 词更具体

这类词应在 specificity score 上靠近高分区域。

9.3 疑似资讯词锚点

例如：

  1. 做法
  2. 推薦
  3. ptt
  4. dcard

这类词往往“具体”，但不一定是理想商品搜索词。
它们用于检验具体度分数是否会把“具体”与“商品意图”混在一起。

9.4 歧义词锚点

例如：

  1. 康乃馨
  2. 玩具
  3. 手機

它们用于观察：

  1. 结构是否容易污染
  2. 分数在歧义簇里是否仍有层次

十、评估指标

本轮验收标准按已确定的 C 口径：

主指标：区分能力

重点看：

  1. 强泛词锚点是否稳定落在低具体度区
  2. 强长尾锚点是否稳定落在高具体度区
  3. 疑似资讯词是否与商品长尾词发生明显混淆

辅指标：结构稳定性

重点看：

  1. root_ratio
  2. singleton_tree_ratio
  3. leaf_ratio
  4. child_count_p50 / p90
  5. depth_p50 / p90
  6. subtree_size_gini
  7. 明显异常边比例

最终抽检

从每种方案里抽三类词：

  1. 低分词
  2. 中间分词
  3. 高分词

再配合浏览器做少量人工复核，确认直觉是否一致。

十一、执行顺序

Phase 1：建图基线

  1. 先跑 A1
  2. 再跑 A2
  3. 比较结构差异

目标：

先拿到词面和频次层面的基础结论。

Phase 2：图结构收紧

  1. 跑 A3
  2. 比较 A2 与 A3

目标：

观察结构正则是否真的提升稳定性。

Phase 3：行为信号增强

  1. 跑 A4
  2. 比较 A3 与 A4

目标：

判断搜索行为信号是否真能改善边质量。

Phase 4：连续分数实验

  1. 在每一版图上都计算： - B1 - B2 - B3 - B4

  2. 比较： - 单路分数 - 融合分数

目标：

确定哪一版 specificity score 最稳。

Phase 5：总评与推荐

  1. 选出： - 最佳建图方案 - 最佳连续分数方案 - 最佳结构与分数组合

十二、最终交付物

本轮实验结束后，应交付：

  1. 台湾建图实验结果对比
  2. 台湾连续分数方案对比
  3. 推荐的结构方案
  4. 推荐的 specificity score
  5. 台湾全量浏览入口
  6. 一份结论文档，说明为什么选这版

十三、当前推荐假设

在真正跑实验之前，当前最看好的组合是：

  1. 建图主方案： Lexical + Frequency + Graph Regularization

  2. 连续分数主方案： specificity_hybrid

原因是：

  1. 只靠词面，信息不足
  2. 只靠曝光，容易把高商业词和高层泛词混淆
  3. 只靠图位置，容易受建图误差放大
  4. 三者联合最有机会得到更强区分能力

但这个结论必须通过实验验证，不应直接当成最终答案。

十四、一句话总结

这轮台湾实验的真正目标是：

先比较多种建图方案，做出一版可信的台湾搜索词结构，再在这版结构上找到一个区分泛词和长尾词的连续分数。
