台湾搜索词结构实验结论

source: TW_SEARCH_TREE_EXPERIMENT_REPORT.md updated: 2026-04-15 19:34 UTC

一、结论

台湾全量搜索词当前推荐采用：

  1. 建图方案：A3 = Lexical + Frequency + Graph Regularization
  2. 连续分数：B4 = specificity_hybrid
  3. 融合权重：lexical = 0.34, graph = 0.33, search = 0.33

这版可以作为“一个词更偏泛词，还是更偏长尾词”的当前依据。

二、为什么选 A3

四版结构里，A3 是最平衡的一档。

A1 的问题

  1. edge_count = 510,017
  2. multi_parent_ratio = 56.65%
  3. max_component_size = 221,140

纯词面图过密，很多 generic 父词会同时挂上去。

A2 的改进

  1. edge_count = 406,576
  2. multi_parent_ratio = 45.65%

频次约束能先压掉一批明显不合理的边，但仍然留了很多“可挂但没必要挂”的泛父词。

A3 的优势

  1. edge_count = 235,247
  2. multi_parent_ratio = 14.72%
  3. root_ratio = 21.96%
  4. subtree_size_gini = 0.8076

A3 的关键点不是把图打散，而是把弱泛父边裁掉。

典型变化：

  1. 麵包超人玩具: [麵包超人, 玩具] -> [麵包超人]
  2. 機車手機架推薦: [機車手機架, 機車, 手機架] -> [機車手機架]
  3. 日本美白牙膏: [美白牙膏, 牙膏] -> [美白牙膏]

这一层更接近“真实上下位”，而不是“只要能包含就算父词”。

A4 没有成为最终方案

  1. edge_count = 226,569
  2. multi_parent_ratio = 11.73%

A4 继续更稀，但提升已经很小。
同时它会继续砍掉一部分仍有用的 generic 父边，例如：

  1. 汪汪隊玩具 -> [汪汪隊]
  2. 皮克敏娃娃 -> [皮克敏]
  3. 機車後照鏡 -> [後照鏡]

如果把台湾搜索词结构当成后续泛词、长尾词判断的基础层，A4 略显过头。

三、为什么选 B4

在 A3 上比较四种分数：

  1. B1 - avg_auc = 0.9936 - objective = 0.9946
  2. B2 - avg_auc = 0.9786 - objective = 0.9855
  3. B3 - avg_auc = 0.8713 - objective = 0.8874
  4. B4 - avg_auc = 0.9991 - objective = 0.99924 - edge_monotonicity = 0.99990 - primary_edge_monotonicity = 1.0

B1

词面分数非常强，但和 surface（词面锚点）共享一部分先验，因此结果会偏乐观。

B2

图位置分数已经能用，解释也直观，但区分力略弱于融合分数。

B3

只看搜索行为明显不够。
它能提供辅助信号，但单独拿来做泛词、长尾词判断不稳。

B4

B4 同时利用：

  1. 词面具体度
  2. 图结构位置
  3. 搜索行为强弱

这版在两类弱监督锚点上都最稳，同时父子边的分数单调性也几乎满分，因此最终采用。

四、分数直觉检查

  2. 波力
  3. 恐龍
  4. 玩具
  5. 樂高

这些词普遍更像泛词或大类词。

高分词

  1. toyotacorollacross鑰匙皮套
  2. jolly迷你鐵盒磁力片40片
  3. dhc速攻藍莓vmax30天份
  4. iphone16promax256g二手價格
  5. dreambaby兒童安全圍欄

这些词大多已经具备品牌、型号、规格、场景或交易条件。

  3. 陶瓷咖啡濾杯
  4. 日本口臭牙膏

中间分区域也基本符合“已经有一定具体度，但还没有收得特别细”的直觉。

五、当前建议怎么用

当前这版更适合先做两个动作：

  1. 把 B4 当成连续具体度分数，先给每个台湾搜索词打一分。
  2. 把 A3 的 DAG 当成结构底座，后续再叠加另一条“商品意图”或“商业价值”轴。

原因很简单：

  1. 这轮已经把“泛词到长尾词”的层次做出来了。
  2. 推薦、ptt、哪裡買 这类资讯词虽然会更具体，但它们和商品词仍是另一条维度。
  3. 因此下一步更合理的做法，是在 A3 + B4 之上再补一条意图分数，而不是重新推翻这一层结构。
